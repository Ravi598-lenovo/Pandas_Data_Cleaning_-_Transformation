# 🧹 Pandas Data Cleaning & Transformation Project

This repository contains a **complete data cleaning and transformation project using Pandas**

The project focuses on **real-world data preprocessing tasks** that are essential before performing any analysis or building machine learning models.

---

## 🧠 Project Motivation

Raw datasets are often:
- messy
- incomplete
- inconsistent
- not ready for analysis

This project demonstrates **how to clean, transform, and prepare data properly using Pandas**, following best practices used in real-world data science workflows.

It is designed to help:
- beginners transitioning to intermediate Pandas
- students learning data preprocessing
- anyone building a strong Pandas foundation

---

## 📊 Dataset Information

- **Dataset:** Titanic Dataset  
- **Source:** Seaborn built-in dataset  
- **Type:** Real-world, semi-structured dataset  
- **Characteristics:**
  - Missing values
  - Categorical and numerical features
  - Outliers
  - Mixed data types

The dataset is loaded directly from a Python library, so **no manual download is required**.

## 📌 Key Concepts Covered

### 🔹 Data Inspection
- Dataset shape and structure
- Column data types
- Missing value detection
- Duplicate row checks

### 🔹 Data Cleaning
- Handling missing values using:
  - median
  - mode
- Dropping columns with excessive null values
- Removing duplicate records
- Standardizing column names

### 🔹 Data Transformation
- Data type conversions
- Feature engineering:
  - family size
  - is_alone flag
  - age groups
- String cleaning and formatting
- Outlier handling using IQR method

### 🔹 Group-Based Analysis
- Aggregations using `groupby()`
- Survival rate analysis
- Average fare calculations
